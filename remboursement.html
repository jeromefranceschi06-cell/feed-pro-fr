Politique de remboursement

Feed Pro est un produit digital (téléchargement immédiat). Voici les règles, formulées clairement.

Principe

Après paiement via Payhip, tu reçois un accès au téléchargement du ZIP. Comme pour la plupart des produits numériques, un remboursement n’est en général pas possible une fois le ZIP téléchargé et utilisable (fichiers accessibles et conformes à la description).

Quand on peut rembourser

Contacte-nous dans les 14 jours suivant l’achat si :

  • le lien ou le ZIP est inaccessible malgré plusieurs essais raisonnables ;
  • le contenu livré ne correspond pas à la description du site (ex. absence manifeste des PNG / textes / plan annoncés) ;
  • un doublon de paiement ou une erreur technique Payhip est avéré.

Dans ces cas, on cherche d’abord une solution (renvoi du lien, fichier corrigé). Si ce n’est pas possible, un remboursement peut être effectué.

Quand on ne rembourse pas

  • le ZIP a été téléchargé et les fichiers fonctionnent comme décrit ;
  • changement d’avis après téléchargement ;
  • besoin non couvert par le produit (ex. coaching, formation live, résultats Instagram) — Feed Pro n’est pas une formation.

Comment demander

Écris à releve.studio@gmx.com avec :

  • l’e-mail utilisé pour l’achat Payhip ;
  • la date d’achat (si connue) ;
  • une brève description du problème (capture ou message d’erreur utile).

On répond sous quelques jours ouvrés. Les remboursements, le cas échéant, passent par le canal de paiement Payhip.
